🚀 Panduan Guru: Upload ke GitHub Pages

Cara Agar Siswa Dapat Mengakses File Ini di HP melalui GitHub

File HTML ini dirancang 100% mandiri (Single-File Web App) tanpa ketergantungan folder eksternal sehingga sangat mudah di-hosting gratis di GitHub Pages:

  1. Buat Repository Baru di GitHub: Login ke akun GitHub Bapak/Ibu Guru, klik New Repository, beri nama misalnya sosiologi-gejala-sosial, pilih Public, lalu klik Create repository.
  2. Upload File HTML Ini: Klik Add file → Upload files. Ubah nama file ini menjadi index.html (atau biarkan namanya gejala_sosial_interaktif.html), lalu klik Commit changes.
  3. Aktifkan GitHub Pages: Buka menu Settings → Pages, pada bagian Branch pilih main dan folder /(root), lalu klik Save.
  4. Bagikan Link ke HP Siswa: Dalam 1 menit, link seperti https://username.github.io/sosiologi-gejala-sosial/ siap dibagikan ke grup WhatsApp atau Google Classroom siswa!
